# 🧠 Cpp_Module

Bu depo, 42 Network kapsamında verilen modern C++ öğrenme yolculuğunun bir parçası olan `C++ Modules` projesini içermektedir. Projede, C++98 standartlarına bağlı kalarak OOP (Object-Oriented Programming) ilkeleri, inheritance, polymorphism, exception handling ve interface kullanımı gibi temel konulara odaklanılmıştır.

## 🗂️ Modül Listesi

| Modül | Açıklama |
|-------|----------|
| **Module 00** | Temel C++ sözdizimi, namespace, member functions, std::string, pointer kullanımı. |
| **Module 01** | Referanslar, heap allocation, stack allocation, class yapıları. |
| **Module 02** | Orthodox Canonical Form, operator overloading, fixed-point numbers. |
| **Module 03** | Inheritance, parent/child class ilişkileri. |
| **Module 04** | Polymorphism, abstract classes, interface, dynamic allocation. |
| **Module 05** | File I/O, exception handling, try-catch yapıları. |
| **Module 06** | STL Containers, iterators, algorithm library kullanımı. |
| **Module 07** | Template kullanımı, function templates, class templates. |
| **Module 08** | Templated containers, stack, queue, custom containers, SFINAE. |

> Her modül, kendine ait bir dizin içerisinde bağımsız olarak derlenebilir ve test edilebilir örnek sınıflar içerir.
